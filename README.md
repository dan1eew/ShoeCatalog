Приложение на WPF с реализацией поиска. 3 задача.
=====================

`Быстрый старт:`
-----------------------------------
  1. Загрузка zip-файла => распаковка
  2. Из папки 3, находящаяся внутри проекта, вытащить базу данных "TableProducts.mdf" и перекинуть в папку Debug "ShoeCatalog\ShoeCatalog\bin\Debug"
  3. Запустить программу "ShoeCatalog\ShoeCatalog.slnx", паралелльно запустив sqllocaldb (комбинация win + r => вводим cmd)
  4. В командной строке ввести команды: sqllocaldb create 5, далее sqllocaldb start 5
  5. После этого запускаем программу и удостоверяемся что он работает.

`Частые ошибки:`
-----------------------------------
  1. При запуске выходит ошибка: **"Не удалось подключиться к базе данных"**, проверьте запущен ли sqllocaldb и создана ли локальная база данных
  Проверить: в командной строке вводим sqllocaldb info 5, должен писать running.
  Также проверьте наличие базы данных "TableProducts.mdf", он должен находиться в "ShoeCatalog\ShoeCatalog\bin\Debug".
  2. При запуске выходит ошибка: **"Ошибка несовместимости базы данных версия 991 (или на подобие)"**, ошибка связано с устаревшей версией sqllocaldb.
  Проверить версию: в командной строке ввести sqllocaldb versions, одна из поддерживаемых версий должна быть Microsoft SQL Server 2025 (17.0.1000.3).
  Если такой нет, то нужно скачать. Для этого нужно в YouTube ввести "Гайд как скачать sqllocaldb для sql server 2025".
